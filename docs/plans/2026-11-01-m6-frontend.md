Status: approved 2026-11-01. Author's decisions: D1 shadcn/ui; D2 no follow-ups (one question per entry); D3 region required, dropdown; D4 to D8 as recommended. **Interface only:** the frontend shows what the pipeline already does and adds no features of its own.

**Goal:** A browser app over the M5 API. The user asks an English question, picks their region, watches the pipeline stages, and reads a plain-language answer with numbered markers. Each marker opens the full provision it came from. Abstention shows as an informational notice. History stays in the browser only.

**Architecture:** A Vite single-page app in `frontend/`. It talks only to the M5 endpoints (`/api/meta`, `/api/ask/stream`, `/api/provisions/{chunk_id}`). It never edits answer text or citations: it renders `GeneratedAnswer` as received and turns `[n]` markers into links to `citations[n-1]`. TypeScript types are generated from the FastAPI OpenAPI schema so the two sides cannot drift.

**Tech Stack:** Node 24 (WSL host, not the `ml` container), Vite 8, React 19, TypeScript, Tailwind CSS 4, shadcn/ui (CLI 4) on Radix, lucide-react icons, TanStack Query 5 (meta and provisions), react-markdown 10 (restricted), React Router (3 routes), Vitest 5 + Testing Library + MSW 3, Playwright for one mocked end-to-end run. Exact versions pinned in `package.json` and `package-lock.json` in Task 1 (no `^` ranges). If TypeScript 7 breaks a tool, pin the last 5.x/6.x that works and record it in the devlog.

**Spec:** `CLAUDE.md` (Core contribution 1 to 4, Frontend, Privacy and ethics, Scope discipline), `src/api/schema.py`, `src/api/stream.py`, `src/generation/schema.py`, M5 plan `docs/plans/2026-10-28-m5-api.md` (API contract).

## Global Constraints

- Answer text and citations are rendered from their separate fields. The frontend never builds a citation label itself; every label comes from `Citation` or `Provision` fields (core contribution 1).
- Wording says a citation shows **where a statement came from**, never that it proves the statement (core contribution 2). No "verified" badges or tick marks.
- `status: "abstained"` and `"insufficient_context"` are styled as information (neutral colour, info icon), never as errors (Frontend section).
- Jurisdiction is visible: the chosen region is always shown in the composer, and each source shows its jurisdiction (core contribution 4).
- Browser-only history in `localStorage`. No analytics, no third-party requests, no fonts or scripts from a CDN at runtime (Privacy and ethics).
- Model text is untrusted: no raw HTML, no links or images from the answer text. Only paragraphs, lists, bold and italic.
- Legal information, not legal advice: the disclaimer is always visible under the composer.
- No features beyond the CLAUDE.md Frontend list without the author's agreement (Scope discipline). The author's rule (2026-11-01): the UI only presents existing pipeline features. Excluded: regenerate, edit question, stop button, copy button, delete or rename history entries, clear-history button, theme switch, share links, voice, file upload, accounts, token streaming, follow-up questions.
- Docs and devlog: plain English, no em dashes.

## Visual direction (the "like ChatGPT" part)

- Left sidebar (260 px, collapsible; drawer on phones): app name, "New question" button, history list (newest first, title = start of the question), "Help" at the bottom.
- Main column centred, `max-w-3xl`, generous line height (`leading-7`), system font stack (no web font download).
- Empty state: "What would you like to know about your employment rights?" centred, composer in the middle of the screen, region question, 4 suggested topic chips (wages, working hours and overtime, leave, termination). Suggestion texts are written fresh, not taken from the gold set.
- Turns: the user question in a rounded grey bubble on the right; the assistant answer as plain prose with no bubble, full width, small GetRight mark on the left.
- Citation markers: small rounded pills with the number (like ChatGPT's source pills), hover tooltip shows the citation label, click opens the source panel.
- Sources block under each answer: numbered list `[1] Employment Act 1955, s. 60A(1) Hours of work`, jurisdiction chip, status chip when not current (Deleted / Superseded / Not yet in force).
- Composer pinned at the bottom: rounded-3xl box, auto-growing textarea, region dropdown and round send button inside; Enter sends, Shift+Enter new line; send is disabled while running. Disclaimer in small grey text below it.
- Source panel: right-side sheet (480 px) on desktop, bottom sheet on phones.
- Follows the system light or dark setting (shadcn CSS variables, no switch); neutral greys, one accent colour.

## Edge cases to test (from the API contract)

1. Answered with citations: markers become pills, Sources block lists each citation once, panel opens the right chunk.
2. Gate abstention (`low_score`, `no_candidates`): information notice listing `abstention.statutes_held`, pointer to the Department of Labour, no Sources block.
3. Language abstention (a Malay question): notice says English only; not an error.
4. `insufficient_context`: notice that the held statutes do not answer this, with the sources that were looked at hidden (they did not support an answer).
5. `external_dependencies` not empty: note "Part of this depends on {statute}, which GetRight does not hold."
6. `notes` not empty: shown under the answer as given.
7. HTTP 503 `generator_unavailable` / 502 `generator_error` / 422 / 500 before the stream starts: the `ApiError.message` with a Retry button.
8. `error` event mid-stream: same message and Retry; any stage spinner stops.
9. Stream ends with no `answer` or `error` event (connection dropped): generic message and Retry.
10. SSE chunk boundaries: an event split across two reads, two events in one read, `\r\n` line endings.
11. `localStorage` missing, full or throwing (private window): the app works, history just is not saved.
12. A stored entry from an older history format: dropped, not crashed on (versioned key).
13. Provision 404 in the panel (index rebuilt since the answer was stored): "This provision is no longer in the corpus (index changed)" with the stored citation label still shown.
14. Deleted / superseded / not-yet-in-force provision in the panel: banner with `deleted_by`, `amended_by` links (open in the panel) or `commencement`.
15. Double Enter / double click on send: one request only.
16. No region chosen: send disabled, dropdown shows the "Where do you work?" placeholder.

## Forward compatibility

Industrial Court awards are in scope but not designed yet. When award chunks arrive, `Citation` and `Provision` may gain award fields (case number, paragraph). The Sources row and panel header read the citation label from the API, so a new chunk type should only need a new header variant in Task 8, not a rewrite.
