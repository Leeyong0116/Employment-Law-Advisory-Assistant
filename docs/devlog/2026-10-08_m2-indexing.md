## 2. What was built
*Report: Implementation (indexing).*

| Module | Job |
|---|---|
| `src/indexing/embed.py` | bge-m3: one pass gives the 1,024-dim dense vector and the learned sparse weights; model released after use (one model on the GPU at a time) |
| `src/indexing/store.py` | PostgreSQL table, upsert, exact cosine search with the jurisdiction filter inside SQL |
| `src/indexing/bm25.py` | BM25 over citation + section title + content; section ids kept whole as tokens |
| `src/indexing/build.py` | One command builds everything; skips work if `chunks.jsonl` is unchanged; writes a manifest |
| `src/indexing/smoke.py` | 7 fixed queries with expected answers |
| `docker-compose.yml`, `docker/ml.Dockerfile` | Database container; ML container with CUDA PyTorch |

Run:
```
docker compose up -d
docker compose run --rm ml python -m src.indexing.build
docker compose run --rm ml python -m src.indexing.smoke
```

## 3. Design decisions
*Report: Design decisions / Justification.*

| Decision | Rationale |
|---|---|
| PostgreSQL in Docker | pgvector has no official Windows build. |
| BM25 in Python (`bm25s`), not inside PostgreSQL | Fewer moving parts; 1,852 chunks need nothing heavier. Dense filtering stays in SQL as CLAUDE.md requires. |
| BM25 indexes citation + title + content; dense embeds content only | Citation text is what makes "section 60E" lookups work; the dense side keeps the CP1 rule unchanged. |
| Exact cosine search, no approximate (HNSW) index | 1,852 vectors scan in milliseconds. An approximate index can return fewer than k rows once a jurisdiction filter applies and is not guaranteed stable; retrieval must be deterministic. |
| Ties broken by `chunk_id` (both dense and BM25) | Same query, same ranked list, every time. |
| Jurisdiction filter by region: Peninsular = EA + IRA; Sabah = Sabah + IRA; Sarawak = Sarawak (Cap. 76 and A1754) + IRA | Core contribution 4: the EA does not apply in Sabah or Sarawak; the IRA applies everywhere. Declared in `config.yaml`. |
| `index_version` = hash of `chunks.jsonl`, stored on every row and in the manifest | Any retrieved chunk can be traced to the corpus build that produced it; browser chat history can store it to detect stale citations. |
| All chunks indexed, including deleted placeholders | "What does section 9 say?" must retrieve "deleted by ..." rather than abstain. |

## 4. Problems met and solved
*Report: Implementation challenges.*

| Problem | Cause | Solution |
|---|---|---|
| bge-m3 failed to load on Windows: `DLL load failed ... An Application Control policy has blocked this file` | Windows 11 **Smart App Control** was on and blocked a native scipy DLL (reached via FlagEmbedding, transformers, scipy). Turning Smart App Control off is irreversible without reinstalling Windows. | ML code moved into a Linux Docker container with GPU access (`--gpus`), verified with `nvidia-smi` inside the container. Security settings unchanged. The same image can run on the Sunway HPC via Apptainer, so local and HPC runs share one environment. |
| Database host differs between Windows (127.0.0.1) and the container (`db`) | Separate network namespaces | `DB_HOST` / `DB_PORT` environment variables override the config. |
| Smoke check counted IRA s.59 as a hit for s.5 | A plain prefix test: `IRA1967_s5` is a prefix of `IRA1967_s59_1` | The expected id must be the whole chunk id or be followed by `_`; unit test added. Ranks re-reported. |

**Smoke checks (top 5):**

| Check | Mode | Filter | Expected | Rank |
|---|---|---|---|---|
| "How many days of annual leave am I entitled to?" | dense | Peninsular | EA s.60E | 1 |
| "section 60E" | BM25 | none | EA s.60E | 1 |
| "How many days of maternity leave do I get?" | dense | Sabah | Sabah "eligible period" definition (98 days) | 1 |
| same question | dense | Sarawak | Cap. 76 s.84 | 1 |
| "Can my employer dismiss me for joining a trade union?" | dense | none | IRA s.5 | 2 (rank 1: IRA s.59, also relevant) |
| "Which services count as essential services?" | dense | none | IRA First Schedule | 2 (rank 1: IRA definition of "essential service") |
| "my boss fired me without telling me, is that allowed?" | dense | Peninsular | EA ss.11 to 14 | 1 (EA s.14(1)) |

No result outside the requested jurisdiction appeared in any filtered check.

**Two observations for M3 and the report:**
1. **Dense rescues what BM25 cannot.** For "my boss fired me without telling
   me", no query word ("boss", "fired", "telling") appears in any chunk, so
   BM25 returns nothing useful (demonstrated during planning). Dense
   retrieval ranks EA s.14 first. This is the case for hybrid retrieval.
2. **Amendment links must be followed at retrieval time.** For Sarawak
   maternity leave, the top hit is Cap. 76 s.84(1), the 2006 text stating
   sixty days, now `superseded`. The A1754 amendment (98 days) is not in the
   top 5 on its own. M3 must pull in `amended_by` chunks
   (`follow_amendment_links: true` in config) or answers will state
   superseded law.

These are sanity checks, not an evaluation; retrieval quality is measured
with RAGAS on the gold set from M3.
