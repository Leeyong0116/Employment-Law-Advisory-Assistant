## 2. Decision: simplify M6

The approved plan (2026-11-01) had 11 tasks including SSE streaming, routing, a browser history store, a Help page and a debug view. Only Tasks 1 and 2 were done. The author is learning frontend, TypeScript and testing on this project and chose a smaller frontend that they can understand and explain.

Reason recorded for the report: the research contribution (retrieval, abstention gate, citations from chunk metadata) is in the backend. The frontend only has to present it honestly.

Changes C1 to C8 (full list in the plan amendment):

- `POST /api/ask` instead of `/api/ask/stream`; one loading message instead of stage progress.
- One page, no routing, no history.
- Plain React state and `fetch`, no TanStack Query.
- Answer shown as plain text with `[n]` markers turned into buttons; no markdown library. React escapes text, so model output cannot inject HTML. Trade-off: `**bold**` shows as typed.
- Source panel shows the cited chunk only (provisos are inside the chunk). Full section later, if time allows.
- Tests for critical behaviour only.

Kept: required region dropdown, disclaimer always visible, citation labels only from API fields, traceability wording (never "verified"), abstention as information not error, essential keyboard accessibility.

## 3. Code

- `frontend/src/api/schema.d.ts`: generated by `npm run gen:types` from `openapi.json`.
- `frontend/src/api/types.ts`: `GeneratedAnswer`, `Citation`, `Provision`, `Meta`, `ApiError`, `Region`. `Region` drops `null`, so the frontend always sends a region (D3).
- `frontend/src/api/client.ts`: `askQuestion` posts `{query, region}`. On a non-2xx reply it throws the API's public message (`PUBLIC_MESSAGES` in `src/api/app.py`); when the reply is not JSON (Vite proxy with FastAPI down) or the network fails, it throws a fallback message. Abstention is a 200 reply, so it passes through as a normal answer.
- `frontend/src/api/client.test.ts` (MSW): sends region and returns the answer; 503 message; non-JSON 502; network failure.
- `frontend/src/App.tsx`: first page, region fixed to `peninsular` (marked TEMPORARY, replaced in step 4b).

Checked: MSW resolves relative URLs such as `/api/ask` against `location.href` in jsdom (`@mswjs/interceptors` fetch interceptor), so the client can use the same paths as the Vite proxy.

`getProvision` and `getMeta` are added when the source panel and disclaimer need them.

## 4. Problems and fixes

- **Root-owned folder.** `frontend/src/api/` was created by `scripts/dump_openapi.py` inside the `ml` container, which runs as root, so `npm run gen:types` failed with `EACCES`. Fixed by the author with `sudo chown -R leeyong:leeyong frontend/src/api`. To avoid it later: run the dump with `docker compose run --user $(id -u):$(id -g) ...`.
- Vitest only picks up `*.test.ts` files; running `client.ts` gives "No test files found".
- Files created in the editor but not saved were empty, giving "No test suite found".
- Tailwind ignores unknown class names silently: `max-w-3x1` and `text-2x` in `App.tsx` are typos for `max-w-3xl` and `text-2xl` (to fix in step 4b).
